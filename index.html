LunaCaffe Point of Sales System

Aplikasi desktop Java Swing untuk pemesanan mandiri pelanggan, antrean kasir, manajemen produk, akun pegawai, rekap transaksi, dan penyimpanan data SQLite. Dokumentasi ini disusun untuk kebutuhan presentasi akademik Tugas Mata Kuliah Pemrograman Berorientasi Objek.

Ruang Lingkup Akademik

1

Latar Belakang

Operasional kafe membutuhkan sistem yang dapat mencatat menu, stok, pesanan, dan transaksi secara konsisten. Studi kasus POS dipilih karena memiliki objek, aktor, dan alur bisnis yang relevan untuk pembelajaran PBO.

2

Tujuan Sistem

Membangun aplikasi desktop yang membantu pemesanan pelanggan, pemantauan pesanan, pengelolaan produk, pengelolaan akun pegawai, dan rekapitulasi transaksi harian.

3

Tujuan PBO

Membuktikan penerapan class, object, encapsulation, inheritance, abstraction, polymorphism, relasi objek, serta pemisahan tanggung jawab antar lapisan program.

Fitur Sistem

Modul Fungsional Terbaru

Pelanggan

  • Katalog menu bergambar dari aset lokal.
  • Pencarian menu, filter kategori, dan sort harga.
  • Keranjang dengan tombol kurang, tambah, dan hapus.
  • Validasi stok sebelum item masuk checkout.
  • Struk checkout dan nomor antrean otomatis.

Kasir

  • Login pegawai melalui portal internal.
  • Melihat antrean pesanan live.
  • Menandai pesanan menjadi selesai.
  • Mengakses halaman rekap operasional.
  • Akses produk dan akun disembunyikan dari role kasir.

Admin

  • Tambah, ubah, dan hapus produk.
  • Restok serta ubah harga produk.
  • Atur kategori, gambar, label NEW, dan label BEST.
  • Tambah dan hapus akun pegawai.
  • Ekspor rekap transaksi harian ke CSV.

Alasan pemisahan lapisan

Pemisahan ini membuat perubahan tampilan, perubahan query database, dan perubahan model data tidak saling bercampur. Pendekatan tersebut sesuai dengan prinsip maintainability dalam pengembangan perangkat lunak berorientasi objek.

Database SQLite

Skema Penyimpanan Lokal

Database tersimpan di file lunacaffe.db. Saat aplikasi berjalan, tabel dibuat otomatis apabila belum tersedia, lalu data awal menu dan akun pegawai ditanam oleh seeder.

Tabel Fungsi Kolom penting
users Menyimpan akun pegawai dan hak akses. id, nama, username, password, role
menus Menyimpan data produk, stok, harga, gambar, dan label menu. id, nama, kategori, harga, stok, image_path, is_new, is_bestseller
orders Menyimpan transaksi utama dan status pesanan. id, nama_pelanggan, total_harga, status, created_at
order_details Menyimpan item menu dalam setiap pesanan. order_id, menu_id, qty, subtotal

Akses database lewat aplikasi

Admin dapat menambah produk, mengubah harga, restok, memilih gambar, dan menghapus produk melalui panel Kelola Produk.

Akses database manual

File lunacaffe.db dapat dibuka dengan DB Browser for SQLite untuk inspeksi tabel dan data transaksi.

Pembuktian PBO

Konsep OOP dalam Kode

Class menjadi cetak biru data, sedangkan object adalah instansiasi yang digunakan saat program berjalan.

Menu menu = new Menu(id, nama, kategori, harga, stok, imagePath, isNew, isBest);
Pesanan pesanan = new Pesanan("TEMP", "Guest", "");

Atribut dibuat private dan diakses melalui method agar perubahan data lebih terkontrol.

private double harga;
public double getHarga() { return harga; }
public void setHarga(double harga) { this.harga = harga; }

Admin dan Kasir mewarisi karakteristik Pegawai sehingga data umum tidak perlu ditulis ulang.

public class Admin extends Pegawai {
    public Admin(String nama, String username, String password) {
        super(null, nama, username, password, "admin");
    }
}

Aktor menjadi class abstrak dan turunannya dapat menjalankan method yang sama dengan perilaku berbeda.

public abstract class Aktor {
    public abstract void masukSistem();
}

Implementasi dan Pengujian

Menjalankan Proyek

Kebutuhan

  • JDK 11 atau versi lebih baru.
  • Apache Maven atau IDE dengan dukungan Maven.
  • Dependensi FlatLaf dan SQLite JDBC sesuai pom.xml.
  • File lunacaffe.db akan disiapkan otomatis saat aplikasi berjalan.

Perintah terminal

mvn clean compile
mvn exec:java -Dexec.mainClass="com.lunacaffe.Main"

Aplikasi juga dapat dijalankan langsung dari IDE melalui file src/main/java/com/lunacaffe/Main.java.

Kesimpulan

LunaCaffe POS menunjukkan bahwa konsep PBO dapat digunakan untuk membangun aplikasi bisnis sederhana secara terstruktur. Pemisahan model, view, DAO, dan utility membuat program lebih mudah dibaca, diuji, serta dikembangkan.
